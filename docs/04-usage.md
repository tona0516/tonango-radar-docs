## 🧭 画面構成とサイドメニュー

画面左端のサイドメニューから、各機能へいつでも切り替えられます。

![左サイドメニューおよび待機画面]({{ '/assets/img/standby_page.webp' | relative_url }})

| メニュー | 機能 |
| --- | --- |
| **戦闘** | 待機画面およびリアルタイムの戦闘統計画面を表示します |
| **履歴** | 過去に記録した対戦一覧と当時の統計画面を閲覧します（詳しくは [📜 戦闘履歴]({{ site.baseurl }}/history/)） |
| **設定** | クライアントパス・全体設定・表示項目のカスタマイズを行います（詳しくは [🎛️ 表示設定・表示項目]({{ site.baseurl }}/settings/)） |
| **更新**（最下部） | アプリ画面をリロードします（キーボードの `F5` キーでも同様にリロードできます） |

> 「**設定**」アイコンに赤い通知バッジが表示されている場合は、新しいバージョンの公開、またはゲームクライアントパスの設定確認が必要です。

## 🔍 マッチ検出と読み込み

1. WoWSでマッチが始まるとリプレイファイル（`tempArenaInfo.json`）を**自動的に検出**し、待機画面から戦闘統計画面へ切り替わります。
2. まずチーム編成・艦名・マップ情報が表示され、続いて統計数値、最後にクラン情報・技能バッジが段階的に反映されます。
3. 自分の行はハイライト表示され、一目で自分の位置を確認できます。

## 🧪 待機中のサンプルプレビュー

「戦闘待機中」画面の上部ヘッダーにある「**サンプル表示で調整**」をクリックすると、サンプルデータ（味方3隻・敵3隻）を用いたプレビューが表示されます。

![サンプルプレビュー画面]({{ '/assets/img/sample_preview.webp' | relative_url }})

- 試合が始まる前に、後述のクイック表示ツールバーや設定画面の表示項目を調整・確認したいときに便利です。
- プレビュー中に実際の戦闘が始まると、自動で本番の戦闘画面に切り替わります。
- 右上の「**終了**」ボタンで待機画面に戻ります。

## 🛠️ クイック表示ツールバー

待機画面・戦闘画面の上部ヘッダー（および「設定」＞「表示設定」の最上部）には、見た目をリアルタイムで切り替えられるツールバーがあります。

![クイック表示ツールバー]({{ '/assets/img/display_toolbar.webp' | relative_url }})

| 操作項目 | 選択肢 / 動作 | 説明 |
| --- | --- | --- |
| **テーブル配置** | `左右` / `上下` | 味方・敵チームのテーブルを左右2ペインで並べるか、上下1ペインにまとめるかを切り替えます（初期値: `左右`） |
| **平均** | `上` / `下` | チーム平均比較バーを統計テーブルの上・下のどちらに配置するかを選びます（初期値: `下`） |
| **枠線** | ON / OFF | テーブルの各セルにグリッド枠線を表示します |
| **K単位** | ON / OFF | `ダメージ`・`最大ダメージ`・`戦闘数` において、`1,000` 以上の数値を `K` / `M` / `G` 単位で省略表示します |
| **高密度** | ON / OFF | カラム幅・セル余白・ヘッダー表記を縮小し、よりコンパクトに1画面へ収めます |
| **倍率** | `50%` 〜 `200%` | アプリ全体のUIズーム率を変更します（初期値: `100%`） |
| **テーマ** | `dark` / `light` | 画面全体の配色テーマ（ダーク／ライト）を切り替えます（初期値: `dark`） |

## 📊 戦闘統計画面

### 戦闘メタ情報バー

画面上部に、現在のマッチの基本情報が表示されます。

- **作戦海域（マップ名）**
- **戦闘種別**（ランダム戦、ランク戦、クラン戦など）
- **自艦名**
- **戦闘開始時刻**
- 統計取得中は「戦績データ解析中...」のインジケータが表示されます

### チーム平均比較

味方チームと敵チームの平均値を、**PR・ダメージ・勝率・戦闘数**の4指標について「艦成績」「総合成績」ごとにゲージで比較します。

### プレイヤー戦績テーブル

「基本情報（プレイヤー・艦）」「艦成績」「総合成績」の3カテゴリで構成されています。
表示する項目や並び順、小数桁数は [🎛️ 表示設定・表示項目]({{ site.baseurl }}/settings/) で自由に変更できます。

> 総合成績の「最大ダメージ」を表示している場合、達成艦艇名をクリックするとブラウザで WoWS Numbers の該当艦艇ページを直接開けます。

## 👤 プレイヤー詳細・⚓ 艦艇詳細モーダル

テーブル内の**プレイヤー名**または**艦艇名**をクリックすると、詳細モーダルが開きます。

![プレイヤー詳細・艦艇詳細モーダル]({{ '/assets/img/detail_modals.webp' | relative_url }})

### プレイヤー詳細モーダル

- **プレイヤー名のコピー**：クリップボードへプレイヤー名をコピーできます
- **プレイヤー戦績（wows-numbers.com）**：ブラウザで該当プレイヤーの WoWS Numbers ページを開きます
- **クラン戦績（wows-numbers.com）**：クランに所属している場合、所属クランの WoWS Numbers ページを開きます

### 艦艇詳細モーダル

- **艦名のコピー**：クリップボードへ艦艇名をコピーできます
- **艦艇統計ページ（wows-numbers.com）**：ブラウザで該当艦艇の WoWS Numbers ページを開きます
- **目安ダメージ一覧表**：その艦艇のサーバー期待値から算出された、レーティング基準（Bad 〜 Super Unicum）ごとの目標ダメージ目安が表示されます
