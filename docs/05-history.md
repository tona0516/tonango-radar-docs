# 戦闘履歴

TonangoRadarでは、マッチの戦績取得が完了すると、その対戦データを自動的にローカルへ記録します。
左端サイドメニューの「**履歴**」（リストアイコン）から過去の戦闘をいつでも振り返ることができます。

![戦闘履歴一覧画面]({{ '/assets/img/history_list.webp' | relative_url }})

## 📋 履歴一覧の確認

履歴画面では、保存されている件数と以下の対戦情報の一覧が新しい順に表示されます。

- **戦闘日時**
- **使用艦艇（自艦）**
- **作戦海域（マップ）**
- **戦闘種別**

## 🔎 過去の統計画面を再表示する

一覧から任意の行をクリックすると、当時の戦闘統計画面が開きます。

- リアルタイム戦闘画面と同じく、**クイック表示ツールバー**でのレイアウト・倍率・テーマ切り替えに対応しています
- プレイヤー名・艦艇名をクリックして**詳細モーダル**や `wows-numbers.com` を開くことも可能です
- 左上の「**戦闘履歴一覧に戻る**」ボタンをクリックすると一覧へ戻ります

> 履歴詳細を表示中に実際の新しいマッチが始まった場合は、サイドメニューの「**戦闘**」から現在の戦闘画面を確認できます。

## ⚙️ 保存件数の設定と仕様

保存件数の上限は、左端サイドメニューの「**設定**」＞「**全体設定**」＞「**履歴保存件数上限**」から変更できます。

- **設定範囲**: `0` 〜 `999` の整数（初期値: `100`）
- **上限を超えた場合**: 新しい戦闘が追加されると、古い記録から自動的に削除されます
- **重複防止**: 同一開始時刻の戦闘は重複して保存されません
- **`0` を設定した場合**: 新しい戦闘履歴は保存されなくなります（既に保存済みの履歴は、次回新しい戦闘が保存されるまで残ります）
