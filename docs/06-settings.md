左端サイドメニューの「**設定**」から、テーブルの表示項目や見た目を細かくカスタマイズできます。
変更内容は即座に保存され、リアルタイム戦闘・サンプルプレビュー・履歴画面のすべてに反映されます。

## 🎨 表示設定の構成

### 1. 全般・レイアウト設定

戦闘画面や待機画面の上部にあるクイック表示ツールバーと同じ項目（配置、チーム平均位置、枠線、K単位、高密度、倍率、テーマ）をここからも変更できます。

### 2. プレイヤー・艦艇情報の設定

基本情報カラム（プレイヤー名・艦名）の表示オプションを設定します。

| 対象 | 設定項目 | 説明 | 初期値 |
| --- | --- | --- | --- |
| **プレイヤー名** | **クラン国籍の国旗を表示** | クラン説明文から言語（日本語・中国語・韓国語）を自動判定し、クランタグの左に国旗を表示します | ON |
| **プレイヤー名** | **文字色タイプ** | プレイヤー名の文字色を `艦成績のPR` / `総合成績のPR` / `なし` から選択します | `なし` |
| **艦名** | **国旗を表示** | 艦種アイコンの左に艦艇の所属国家アイコンを表示します | ON |

> ※クランタグの文字色は、クラン戦の所属リーグに基づく色が自動で適用されます。

### 3. 統計カラム設定（表示項目 / 表示順 / 小数部桁数）

「**艦成績カラム**（14項目）」と「**総合成績カラム**（15項目）」のタブを切り替えて設定します。

![統計カラム設定画面]({{ '/assets/img/settings_columns.webp' | relative_url }})

- **表示トグル**: スイッチを ON にすると「表示中の項目」リストの末尾に追加され、OFF にすると「非表示の項目」へ移動します
- **表示順変更**: 「表示中の項目」の右端にある `▲` / `▼` ボタンで、テーブルの左から右への並び順を変更できます
- **小数部桁数**: 対応項目について `0` / `1` / `2` 桁から選択できます（※桁数設定は「艦成績」と「総合成績」で共通です）

### 4. デフォルトに戻す

表示設定セクション右下の「**表示設定をデフォルトに戻す**」ボタンをクリックすると、確認ダイアログのあと、すべての表示設定・カラム並び順が初期状態にリセットされます。

## 📊 統計項目リファレンス

設定可能な全 17 種類の統計項目は以下の通りです。

| 項目名（高密度時） | 対応カテゴリ | デフォルト表示 | 桁数設定 | 説明 |
| --- | --- | --- | --- | --- |
| **PR** (`PR`) | 艦 / 総合 | 艦: ON / 総合: ON | ○ (`0`) | WoWS Numbers 互換の Personal Rating（[表示色について]({{ site.baseurl }}/color/) 参照） |
| **勝率** (`勝率`) | 艦 / 総合 | 艦: ON / 総合: ON | ○ (`1`) | 勝率（%） |
| **ダメージ** (`ダメ`) | 艦 / 総合 | 艦: ON / 総合: OFF | ○ (`0`) | 1戦あたりの平均与ダメージ（艦成績のみレーティング色分け対応） |
| **最大ダメージ** (`最大`) | 艦 / 総合 | 艦: OFF / 総合: OFF | — | 艦: 使用艦の最大与ダメージ / 総合: 全艦艇での最大与ダメージと達成艦名（リンク付き） |
| **K/D** (`K/D`) | 艦 / 総合 | 艦: ON / 総合: OFF | ○ (`1`) | キルデス比（撃沈数 ÷ 撃沈された回数 ※未撃沈時は分母 1 として計算） |
| **撃沈** (`撃沈`) | 艦 / 総合 | 艦: OFF / 総合: OFF | ○ (`1`) | 1戦あたりの平均撃沈数 |
| **経験値** (`EXP`) | 艦 / 総合 | 艦: OFF / 総合: OFF | ○ (`0`) | プレミアムアカウント補正された1戦あたりの平均取得経験値 |
| **戦闘数** (`戦数`) | 艦 / 総合 | 艦: ON / 総合: ON | — | 戦闘数（PvP） |
| **分艦隊比** (`分隊`) | 艦 / 総合 | 艦: OFF / 総合: OFF | ○ (`1`) | 戦闘数に対する分艦隊戦闘数の割合（`1`〜`3`）。`1` はすべてソロ、`3` はすべて3人分艦隊を意味します |
| **技能バッジ** (`バッジ`) | 艦 / 総合 | 艦: ON / 総合: OFF | — | 艦艇熟練度バッジ。艦: 使用艦のバッジ（`E` / `1st` / `2nd` / `3rd`） / 総合: Expert, 1st, 2nd, 3rd の各取得艦数 |
| **撃墜** (`撃墜`) | 艦のみ | 艦: OFF | ○ (`1`) | 航空機の1戦あたりの平均撃墜数 |
| **命中率** (`命中`) | 艦のみ | 艦: OFF | ○ (`1`) | 主砲 / 魚雷の命中率（<code>主砲% &#124; 魚雷%</code>） |
| **生存率(詳細)** (`生存(詳)`) | 艦 / 総合 | 艦: OFF / 総合: OFF | ○ (`1`) | 全戦闘 / 勝利時 / 敗北時それぞれの生存率（<code>全体% &#124; 勝% &#124; 敗%</code>） |
| **生存率(全体)** (`生存(全)`) | 艦 / 総合 | 艦: OFF / 総合: OFF | ○ (`1`) | 全戦闘での生存率（%） |
| **平均Tier** (`平均T`) | 総合のみ | 総合: ON | ○ (`1`) | 使用艦艇の加重平均Tier |
| **Tier帯比** (`Tier帯`) | 総合のみ | 総合: OFF | ○ (`1`) | 使用艦艇のTier帯割合（`Low: 1~4` / `Mid: 5~7` / `High: 8~★` のバーチャート） |
| **艦種比** (`艦種`) | 総合のみ | 総合: OFF | ○ (`1`) | 使用艦艇の艦種割合（潜水艦 / 駆逐艦 / 巡洋艦 / 戦艦 / 空母 のバーチャート） |

> ※「`K単位`」ツールバーオプションを有効にすると、**ダメージ・最大ダメージ・戦闘数**の 1,000 以上の数値が `K` / `M` / `G` 単位で省略表示されます。

## 🧰 システム・サポート情報

設定画面の最下部では、以下の操作・確認が行えます。

- **設定データフォルダ**: 設定ファイル（`globalPref` / `displayPref`）や戦闘履歴（`history.json`）が保存されているフォルダを開きます
- **キャッシュフォルダ**: キャッシュデータおよびアプリのログファイルが保存されているフォルダを開きます
- **ユーザマニュアル**: 本マニュアルサイトをブラウザで開きます
- **バージョン**: 現在起動中のアプリケーションバージョンを確認できます
