# トラブルシューティング

お困りの場合は、以下の項目をご確認ください。

## ❌ マッチが検出されない

以下を確認してください：

1. 「設定」＞「ゲームクライアントパス設定」に `WorldOfWarships.exe` があるフォルダが**正しく設定**されているか（Game Center版・Steam版どちらも同様です）
2. 「設定」＞「全体設定」で**プレイするサーバー**が正しく設定されているか
3. 他のMod等で**リプレイの記録を無効化**していないか（アプリは `replays` フォルダ配下の `tempArenaInfo.json` を監視しています）
> 参考: [リプレイを記録、無効化、視聴する方法 - World of Warships](https://wargaming.net/support/ja/products/wows/article/15038/){:target="_blank"}

## 👤 戦績欄に「PRIVATE」「N/A」「ERROR」と表示される

テーブル内の表示にはそれぞれ以下の意味があります。

| 表示 | 意味・原因 |
| --- | --- |
| **`PRIVATE`** | プレイヤーがWargaming側で戦績を**プライベート（非公開）設定**にしているため、WG APIから情報を取得できません。API側の制限でありアプリの不具合ではありません。 |
| **`N/A`** | その艦艇での PvP 戦闘数が `0`（初乗り等）、または PvP の戦闘記録がないプレイヤーです。また、期待値データが存在しない艦艇では PR が `N/A` となります。 |
| **`ERROR`** | 該当プレイヤーやカテゴリ（艦成績・総合成績・技能バッジ）のデータ取得に失敗しています。一時的な通信エラーの可能性があります。 |

## ⚠️ 警告トーストやエラー画面が表示される

### 画面右上に警告通知（`[W...]`）が出る場合

一部のAPI通信（総合成績、一部プレイヤーの艦成績・バッジ・クラン情報、期待値など）が失敗した場合に警告が表示されます。取得できたデータ範囲はそのまま表示されますので、一時的なAPI負荷の場合は次のマッチで自動的に回復します。

### 待機画面にエラーメッセージ（`[E...]`）が出る場合

エラーメッセージと「**再試行**」ボタンが表示される場合は、ボタンをクリックして再試行してください。

| エラーコード帯 | 主な原因と対処 |
| --- | --- |
| `[E1001]`〜`[E1202]` | WG API や WoWS Numbers との通信失敗です。インターネット接続を確認のうえ、時間をおいて「再試行」してください。 |
| `[E1501]`〜`[E1508]` | バージョン確認またはアプリ内更新のエラーです。再試行するか、手動で[ダウンロードページ]({{ site.baseurl }}/install/)から最新版を導入してください。 |
| `[E2101]`〜`[E2202]` | リプレイファイルまたはゲームクライアントパスの問題です。設定画面で `WorldOfWarships.exe` のあるフォルダを再設定してください。 |

また、画面表示が崩れたり反応しなくなった場合は、左端サイドメニュー最下部の「**更新**」ボタン（またはキーボードの `F5` キー）でアプリをリロードしてください。

## 🌐 サーバーを変更したが反映されない

サーバー（リージョン）変更は**次のマッチから**反映されます。現在のマッチ中には反映されませんのでご注意ください。

> ※**クラン戦**では、設定したサーバー（味方側）と異なるリージョンの敵チームとマッチングした場合も、敵チームのリージョンを自動判別して戦績を取得します。

## 💬 解決しない場合は

上記で問題が解決しない場合は、お気軽にDiscordのDMまでご連絡ください。不具合の報告や質問など、何でもお受けしています。

> お問い合わせの際、設定画面最下部の「システム・サポート情報」＞「**キャッシュフォルダ**」内にあるログファイルや表示されたエラーコード（`[E...]`）を添えていただくと調査がスムーズです。
